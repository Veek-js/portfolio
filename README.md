# Veekshith — Portfolio

Personal portfolio. Dark editorial style, lime-on-black, set in Instrument Serif
& Space Grotesk. Built with React + Vite.

- Minecraft plugins, Discord bots, websites — with fixed commission pricing
- Discord-first contact (no contact-form slop)

## Run it

```bash
npm install
npm run dev
```

## Deploy

Static output — `npm run build`, publish `dist/`.
`netlify.toml` is included for Netlify drop-in deploys.
